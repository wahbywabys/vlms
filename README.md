# VTC_LMS downloads

- VTC_LMS-demo.zip: one-file offline demo. Unzip, then double-click VTC_LMS-demo.html.
- VTC_LMS-center-package.zip: offline centre server package (includes the WABYS curricula).
- WABYS-3D-VR-Labs.html: 3D & VR labs for all 15 programmes in one file. Download it and open it in any browser (Chrome, Edge, Safari).
